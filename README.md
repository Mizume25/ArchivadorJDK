# Archivador de Ejercicios Java

## Objetivo y conclusiones
Este repositorio recoge mi trabajo con Java durante el periodo de Noviembre 2025 
a Enero 2026, y representa el inicio de mi formación como programador. Java fue 
mi primer lenguaje, y aquí están los fundamentos que construí desde cero.

Durante este periodo cubrí los conceptos esenciales: declaraciones e 
inicializaciones, condicionales y bucles, arrays y matrices, y funciones.

Posteriormente continué el aprendizaje en local, profundizando en programación 
orientada a objetos, control de errores, interfaces y clases abstractas, y 
arquitecturas base.

Este recorrido me dio la base lógica y estructural que luego apliqué al aprender 
PHP, y que está presente hoy en proyectos como [MizumeBlog](https://mizumeblog.es/), construido 
con Laravel, React y TypeScript.
